# Submission and source checklist

Target: Professional Agents. Deadline Sep 14, 2026 17:00 PDT = Sep 15, 2026 05:30 Asia/Kolkata. Recheck official updates before submitting. This is a technical checklist, not an eligibility determination for every teammate.

- [ ] Each entrant reviews eligibility and team requirements.
- [ ] AWS account and AWS Builder ID ready.
- [ ] New project uses Strands for actual agent work.
- [ ] Public GitHub repository with source, assets, verified setup instructions and MIT or Apache-2.0 license.
- [ ] Disclose incorporated pre-existing work accurately.
- [ ] Architecture diagram matches deployed implementation.
- [ ] Public YouTube/Vimeo video no longer than five minutes, showing working project and problem/audience/value.
- [ ] English submission materials or required translation.
- [ ] Working judge access and credentials provided in submission instructions; free access maintained through judging end.
- [ ] Claims and screenshots match actual implementation; live demo link encouraged.
- [ ] Optional builder.aws article follows current bonus rules, if time permits after working submission.
